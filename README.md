## 🎯 Sobre o Repositório

> 📌 **Objetivo:** Documentar e centralizar a evolução técnica no desenvolvimento Web e Front-end moderno ao longo do semestre no SENAI. Aqui você encontra anotações detalhadas de cada aula, materiais em PDF e a coleção completa de projetos práticos implementados, desde interfaces clássicas em Vanilla JS até SPAs e SSR com React, Next.js, Vue, Angular e integração com APIs em Node.js.
